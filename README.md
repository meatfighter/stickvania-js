# Stickvania JS

Repository layout:

- `desktop/` contains the archived legacy Java project material and desktop build.
- `pwa/` contains the TypeScript browser PWA port.
- `scripts/` contains build and release helpers.
- `dist/` is generated by production builds.
- `releases/` contains intentionally committed downloadable desktop artifacts.

Useful commands:

- `npm.cmd run dev` starts the PWA dev server.
- `npm.cmd run build:web` builds only the PWA.
- `npm.cmd run build:desktop` builds the legacy Java desktop jar and zip.
- `npm.cmd run release:desktop` refreshes the committed desktop release zip.
- `npm.cmd run build` builds the full release bundle.
- `npm.cmd run run:desktop` launches the built desktop jar with the local Windows native libraries.
